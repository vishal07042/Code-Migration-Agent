# Replay UI (optional, Milestone 9)

React + Vite + Tailwind + Framer Motion iteration replay.

```bash
cd web
npm install
npm run dev      # serves the app; report JSON is generated by:
cd .. && uv run python eval/report.py   # writes public/run-report.json
npm run build    # verified: dist/ with contract-checked run-report.json
```

The app fetches `run-report.json` (`version`, `generated_at`, `modules[]`,
`traps[]`) and renders module agreement plus per-trap caught/missed motion
list items. `eval/report.py::write_replay` owns that contract, covered by
`tests/test_web.py`.
